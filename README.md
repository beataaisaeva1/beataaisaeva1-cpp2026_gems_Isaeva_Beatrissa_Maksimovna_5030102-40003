# GEMS
Игровое поле разбито на квадраты разных цветов. Можно поменять 2 соседних местами, кликнув сначала на одном, потом на другом. Если в результате таких манипуляций 3 или более квадрата одного цвета оказались соседними (не обязательно попарно), они уничтожаются, остальные квадраты сдвигаются вниз, производится еще одна проверка на образование последовательности одноцветных и тд. При уничтожении квадрата может выпасть рандомный бонус в окрестности радиуса 3 квадратов, совершающий следующее:
1) Перекрашивание квадрата, куда попал бонус, и его произвольных 2 НЕсоседей в окрестности в цвет исходного квадрата, откуда выпал бонус
2) «Бомба» - уничтожает 5 произвольных квадратов на поле, включая тот, куда попала

# Среда разработки
Visual Studio 2022

# Как скачать SFML через GitHub
1. Открыть GitHub:
https://github.com/SFML/SFML.
2. Справа открыть раздел Releases.
3. Найти релиз 2.6.2.
4. Раскрыть пункт Assets.
5. Скачать архив:
SFML-2.6.2-windows-vc17-64-bit.zip.
Данная версия подходит для Visual Studio 2022 (64-bit).
6. После скачивания распаковать архив, например, в папку:
C:\SFML\SFML-2.6.2.
Внутри должны находиться папки:
include  
lib  
bin

# Как запустить проект
В Visual Studio 2022 создать новый проект:
Console App C++.
После создания проекта открыть файл с кодом и вставить туда содержимое main.cpp.

Открыть свойства проекта:
Проект - Свойства.
Сверху выбрать:
Конфигурация: Все конфигурации.  
Платформа: x64.

Слева открыть:
C/C++ - Общие.
Справа найти:
Дополнительные каталоги включаемых файлов.
Добавить путь:
C:\SFML\SFML-2.6.2\include.
Слева открыть:
Компоновщик - Общие.
Справа найти:
Дополнительные каталоги библиотек.
Добавить путь:
C:\SFML\SFML-2.6.2\lib.
Слева открыть:
Компоновщик - Ввод.
Справа найти:
Дополнительные зависимости.
Добавить:
sfml-graphics.lib  
sfml-window.lib  
sfml-system.lib
После этого нажать:
Применить - ОК.

Открыть папку:
C:\SFML\SFML-2.6.2\bin.
Скопировать файлы:
sfml-graphics-2.dll  
sfml-window-2.dll  
sfml-system-2.dll
И вставить их в папку проекта рядом с .exe файлом
